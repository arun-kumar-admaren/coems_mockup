#### **USER Story:**

**As a user,**
**I want to** see and manage all tasks for an Engineering Project in one consolidated list
**So that** I don't have to open every discipline sub-tab to know what work is outstanding on the project.

---

#### **acceptance criteria:**

1. The project-level **Tasks** tab must show a consolidated list of every task created across all Engineering Tasks disciplines (Hydro, Structural, CAD, Projects, Cargo Planning, Others) for this project.

2. An **"Add Filter"** control must let the user filter this consolidated task list (e.g. by discipline, status, or assignee).

3. An **"Add Task"** button must let the user create a new task directly from this tab.

4. Each task row must show a status badge and a kebab menu (⋮) for task-level actions (e.g. edit, delete, log time).

5. The tab must show a **"Total Effective Time"** summary — the sum of logged time across all tasks in the project.

6. The tab must include a collapsible **History** section logging task-list-level changes.

7. Tasks added or edited here must stay in sync with the same task appearing under its originating discipline in the **Engineering Tasks** tab, and with the global **Engineering Task** module (see "Engineering - Task Tracker").
