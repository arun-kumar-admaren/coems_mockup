#### **USER Story:**

**As a user,**
**I want to** see Engineering-related vessels/projects plotted on a map
**So that** I get a geographic overview of where active engineering work is located.

---

#### **acceptance criteria:**

1. The **Map** sidebar item (marked **BETA**) must open an interactive map (Google Maps-based) showing colour-coded pins for vessels/projects.

2. The map must support standard pan/zoom interaction.

3. A list/print toggle must be available near the top-left of the map to switch to a tabular view of the same plotted records, or to print the current view.

4. Because this feature is explicitly labelled **BETA**, its pin data, colour legend, and click-through behaviour must be confirmed with the Engineering team before being treated as a stable, supported feature — this story should be revisited once Map exits beta.
