#### **USER Story:**

**As a user,**
**I want to** search across every document uploaded anywhere in the Engineering module
**So that** I can find a file without remembering which project or discipline it was attached under.

---

#### **acceptance criteria:**

1. The **Document Search** sidebar item must open a dedicated search page with a Search box and an **"Add Filter"** control.

2. Search must cover files uploaded via any Engineering Project's project-level **Files** tab and any discipline-level **Files** section inside **Engineering Tasks** (see "Engineering - Files Tab" and "Engineering - Engineering Tasks Tab").

3. When no search/filter has been entered, or no results match, the page must show a **"No Records Found..."** empty state.

4. Each search result must show enough context (file name, originating Engineering Project, discipline if applicable, upload date/user) to identify the file and jump to its source record.

5. This search must be the same underlying capability exposed as **"Document Manager"** from the Engineering listing's kebab menu (see "Engineering - Listing Page").
