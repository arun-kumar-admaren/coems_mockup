#### **USER Story:**

**As a user,**
**I want to** attach project-level files to an Engineering Project
**So that** documents relevant to the whole request (not one discipline) are stored with the record.

---

#### **acceptance criteria:**

1. The project-level **Files** tab must let the user upload one or more files against the project.

2. Uploaded files must be listed with at least file name and upload date, and must be downloadable.

3. Files uploaded here must be distinct from files uploaded inside a specific **Engineering Tasks** discipline sub-tab (see "Engineering - Engineering Tasks Tab"), which are scoped to that discipline only.

4. Files attached anywhere in the project (project-level or discipline-level) must be discoverable via the global **Document Search** and **Document Manager** — see "Engineering - Document Search".
