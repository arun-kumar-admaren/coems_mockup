#### **USER Story:**

**As a user,**
**I want to** hold a project-level conversation on an Engineering Project
**So that** general discussion about the request that isn't specific to one discipline is kept in one place.

---

#### **acceptance criteria:**

1. The **Comments** tab must show a **"Start New Conversation"** button.

2. Clicking **"Start New Conversation"** must let the user post a text comment, visible to anyone with access to the project.

3. Comments posted here must be distinct from the discipline-scoped conversations available inside each **Engineering Tasks** sub-tab (see "Engineering - Engineering Tasks Tab") — this tab is project-wide, not discipline-specific.

4. Each comment must show the posting user and timestamp.
