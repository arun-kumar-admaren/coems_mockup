#### **USER Story:**

**As a user,**
**I want to** manage quotations against an Engineering Project
**So that** the cost of the engineering work can be quoted, tracked, and referenced from the same record as the request.

---

#### **acceptance criteria:**

1. The **Quotations** tab must list all quotations raised against the project, if any exist.

2. When no quotations exist, the tab must show an empty state (no quotations recorded).

3. The tab must include a collapsible **History** section logging quotation-related changes.

4. Users with the relevant permission must be able to add a new quotation from this tab, capturing at minimum a quoted amount and status.

*(Note: this record's Quotations tab was empty in UAT at the time of documentation — quotation creation fields should be confirmed against a record with an existing quotation before this story is finalized.)*
